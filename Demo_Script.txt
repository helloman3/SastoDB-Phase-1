1. Create a table with full constraints
CREATE TABLE students (id INT PRIMARY KEY, name TEXT UNIQUE, score INT NOT NULL);

2. Insert valid records (SUCCEEDS)
INSERT INTO students VALUES (1, Alex, 92);
INSERT INTO students VALUES (2, Bella, 88);

3. Constraint enforcement tests (ALL SHOULD FAIL WITH ERRORS)

INSERT INTO students VALUES (3, Alex, 90);      -- Error: Duplicate UNIQUE 'Alex'
INSERT INTO students VALUES (4, David, NULL);   -- Error: NOT NULL violation on 'score'

4. View initial table
SELECT * FROM students;

5. Update and Delete operations
